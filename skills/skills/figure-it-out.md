summary: Design a rigorous, auditable approach when no existing playbook fits.
---
No bundled playbook fits this task. Design one: state the goal and how success will be proven, list the risks, choose the smallest sequence of verifiable steps, and decide which steps can run in parallel.
Write the playbook to `.majstack/playbooks/custom-<slug>.toml` with keywords, description and steps drawn from existing skills, then execute it, keeping a decision trail in `.majstack/decisions.tsv`.
