group: plan
mode: write
summary: Review a developer-facing plan for onboarding and friction.
---
Modes from arguments: expansion, polish, triage. Define developer personas, benchmark time-to-hello-world against comparable tools, design the magical first moment, and walk each onboarding step naming friction (setup, errors, docs gaps, naming). Score each area 0 to 10 and amend the plan. Save scores to `docs/devex-scores.md` so the live audit can compare. End with `VERDICT: APPROVE` or `VERDICT: REJECT: <reasons>`.
