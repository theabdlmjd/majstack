name: design-plan-review
group: plan
mode: write
summary: Rate the plan's design dimensions 0-10 and raise each to a 10.
---
Rate each dimension 0 to 10 for the planned UI: information hierarchy, spacing and rhythm, typography, color, interaction states (empty, loading, error), responsiveness, accessibility, and distinctiveness. For each, say what a 10 looks like and edit the plan to get there. Flag generic 'template' looks: default gradients, stock card grids, meaningless icons, filler copy. End with `VERDICT: APPROVE` or `VERDICT: REJECT: <reasons>`.
