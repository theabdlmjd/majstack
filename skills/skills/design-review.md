Use `majstack browse` to audit the running UI with the same dimensions as the design plan review. Fix issues with atomic commits and before and after screenshots. Flag generic template looks and accessibility gaps (contrast, focus, labels). End with `VERDICT: APPROVE` or `VERDICT: REJECT: <reasons>`.
